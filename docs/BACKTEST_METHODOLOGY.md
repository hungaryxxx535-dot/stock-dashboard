# 回测方法

回测使用严格时间排序的事件流，并复用`PaperBroker`：信号形成后，只能在下一根时间更晚且可交易的K线撮合；收盘信号不得按同日收盘价或同K线最低价成交。未成交订单在结束时保留为`EXPIRED`，不会删除。

撮合包括资金冻结、T+1、停牌、涨跌停一字板、最小100股、成交量参与率、部分成交、佣金最低收费、卖出印花税、滑点和冲击成本。费率是回测参数，必须按历史日期版本化；默认值只是模型配置，不代表永远有效的法规。

`build_walk_forward_splits`把开发期分成扩展训练集、验证集和滚动样本外窗口，并永久保留相同的一次性最终holdout。随机基准必须固定种子；报告保存数据版本、策略版本和参数版本。

输出覆盖交易数、胜率、盈亏比、Profit Factor、期望、累计/年化收益、最大回撤、Sharpe、Sortino、Calmar、连续亏损、持有期、MFE/MAE、未成交率、滑点和费用、策略分组及收益集中度。没有行业或市场环境标签时，对应分组保持空字典，禁止伪造。

当前`quant:smoke`使用`TEST_FIXTURE`日线近似，目的仅是端到端验证。由于真实点时数据不完整，目前没有可发布的可信回测收益结果。
