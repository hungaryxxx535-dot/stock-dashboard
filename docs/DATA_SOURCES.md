# 数据源与完整性

## AkShare

适配器：`hermes_quant/data/akshare_provider.py`。

- 当前上市证券：上交所主板、科创板和深交所A股列表，包含真实上市日期。
- 日线：`stock_zh_a_hist`，不复权原始OHLCV，记录抓取时间、数据时间和内容哈希版本。
- 5分钟线：东方财富失败时回退新浪 `stock_zh_a_minute`，按请求区间过滤，保存原始来源和哈希版本；它不是09:25委托簿或集合竞价快照。
- 行业历史：巨潮 `stock_industry_change_cninfo`。抓取时刻写入`announced_at`，历史回测必须同时检查有效期和已知时间。
- 公告：东方财富公告API，按证券与日期区间分页读取，保存公告编号、发布时间和原始链接。
- 失败策略：超时、指数退避重试、限速、本地缓存恢复；缓存恢复必须标记 `stale=true` 和原始错误。
- 代理：只从 `HERMES_HTTP_PROXY` 配置读取，禁止业务代码硬编码。AkShare内部请求是否完全遵循代理取决于对应上游接口，部署前需单独健康检查。
