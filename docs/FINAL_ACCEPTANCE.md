# 股票作战平台最终阶段验收

验收日期：2026-09-03（Asia/Shanghai）

## 已交付闭环

1. 持仓：A股、美股、港股分区，本地 OCR/CSV 导入、名称匹配、人工确认、导入前快照。
2. 市场：多来源行情与宏观聚合，记录来源、时间、新鲜度和失败降级。
3. 作战台：数据、风险、计划、警报和复盘聚合，生成分级任务与决策准备度。
4. 研究：结构化证据、反证、风险、催化剂、失效条件和观察池。
5. 计划：方向、目标仓位、行动条件、失效条件、期限和受控状态机。
6. 风控：仓位与集中度规则、压力测试、警报同步、处置记录。
7. Paper：仅允许已核验 A 股计划进入本机模拟委托台，支持账户、持仓、委托、拒绝原因和撤销。
8. 复盘：计划关联、实际行动、是否遵守计划、过程质量、结果质量及日/周/月汇总。
9. 运维：系统健康页、数据源明细、本地/云同步状态和 Paper 安全状态。

## 安全结论

- 浏览器不接收量化 API Token；服务端代理只接受 HTTP 回环地址。
- 非 `paper` 环境响应会被拒绝。
- 不包含真实券商登录、SDK、会话或真实订单提交能力。
- 云端预览无法访问用户电脑上的回环 Paper 服务，会明确显示未就绪。
- 自动调度和前向推送继续默认关闭。

## 明确限制

- 09:25 集合竞价委托簿和全市场 Point-in-Time 历史覆盖仍未达到上线门槛，因此不得宣称全市场回测可信。
- Paper Broker 的真实前向观察期不能被测试夹具代替；Champion 首次评审至少需要 20 个完整模拟交易日，可靠评估至少 60 日。
- AI 总结属于可选增强；没有模型配置时，核心持仓、计划、风控、Paper 和复盘功能仍完整可用。
